# 🧠 Memória do Projeto

> Contexto persistente do projeto. Os agentes consultam estes arquivos antes de tomar decisões.

---

## Arquivos de Memória

### [[padroes-tecnicos|Padrões Técnicos]]
Templates CSS, convenções de código, estrutura de arquivos.  
**Consulte antes de criar qualquer material novo.**

> Reutilizável entre projetos — não requer alterações ao trocar de turma.

---

## Arquivos da Turma

Os seguintes arquivos são específicos de cada turma e devem ser criados ao iniciar um novo projeto:

| Arquivo | Finalidade |
|---------|-----------|
| `perfil-turma.md` | Perfil da turma, ritmo, contexto temático |
| `decisoes.md` | Decisões pedagógicas e técnicas |
| `feedback-aulas.md` | Feedback pós-aula do professor |
| `feedback-aluno.md` | Feedback individual por aluno |
| `status-aulas.md` | Progresso das aulas |

> Use os templates em `_templates/` como ponto de partida.

---

## Regras de Uso

1. **Antes de agir** → Leia os arquivos de memória relevantes
2. **Após agir** → Atualize o status e registre decisões/feedbacks
3. **Nunca apague** → Histórico é imutável, apenas adicione
4. **Sempre data** → Toda entrada precisa de data

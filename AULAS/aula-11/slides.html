⏱️ setInterval — Repetir a Cada X ms

let intervalo = setInterval(function() {
    console.log("Leitura a cada 3 segundos!");
}, 3000);  // 3000ms = 3 segundos

// Para parar:
clearInterval(intervalo);

IoT: é exatamente assim que um sensor coleta dados periodicamente!

📝 Template Literals

let temp = 25;
let hora = new Date().toLocaleTimeString("pt-BR");

// Antes (concatenação):
console.log("Temp: " + temp + "°C às " + hora);

// Agora (template literal — use crase `):
console.log(`Temp: ${temp}°C às ${hora}`);

💡 Template literals usam crase (`) e ${variavel} para inserir valores!

✅ O que aprendemos hoje

  • setInterval(fn, ms) executa código repetidamente
  • clearInterval(id) para a execução
  • setTimeout(fn, ms) executa uma vez após atraso
  • Template literals (`texto ${var}`) facilitam strings
  • new Date() fornece data/hora atual

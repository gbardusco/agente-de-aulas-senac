🎯 Objetivo do Projeto Final

O Dashboard IoT será a interface de controle de uma casa inteligente simulada.

Requisitos de Interface:

  • Header com status online/offline
  • Seção de Leituras (sensores)
  • Seção de Controles (atuadores)
  • Seção de Log de Eventos

Hoje o foco é 100% HTML + CSS.

Vamos estruturar os "blocos" e deixá-los bonitos usando Flexbox e variáveis CSS.

📐 Planejamento Visual (Wireframe)

🏗️ Estrutura Semântica

<header>...</header>
<main>
    <section class="sensores">...</section>
    <section class="controles">...</section>
    <section class="log">...</section>
</main>
<footer>...</footer>

💡 Separe as áreas com <section> para manter o código organizado. Use um <div class="container"> dentro delas para alinhar com Flexbox.

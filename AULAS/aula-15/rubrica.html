Rubrica de Avaliação — Dashboard IoT (UC14)

Documento de apoio para avaliação dos indicadores previstos no Plano de Curso.

Critério / Indicador Insuficiente (Desenvolvimento) Parcial (Atende Parcialmente) Pleno (Atende)
HTML Semântico & Layout CSS

(Indicador: Estrutura páginas web usando HTML e CSS)		 Insuficiente
A página carece de estrutura semântica ou o layout está completamente quebrado. CSS é inexistente ou aplicado de forma errada (só inline).		 Parcial
Usa HTML estruturado e arquivo CSS externo, mas o layout apresenta falhas de alinhamento ou não utiliza Flexbox adequadamente.		 Pleno
Interface bem estruturada (header, main, section). Flexbox usado corretamente, garantindo alinhamento. Design agradável (variáveis CSS, cores coerentes).
Manipulação do DOM & Eventos

(Indicador: Desenvolve scripts para interatividade)		 Insuficiente
Os botões não funcionam e a página é estática. Não consegue capturar cliques ou alterar elementos visuais via JS.		 Parcial
Consegue capturar cliques e alterar alguns textos/cores, mas apresenta bugs visuais ou mistura muito JS no HTML (uso excessivo de onclick).		 Pleno
Botões atualizam a interface dinamicamente via `addEventListener`. Uso eficiente de `.textContent` e `.classList` para refletir o estado.
Lógica, Temporizadores e Condicionais

(Indicador: Simula comportamento de dispositivos IoT)		 Insuficiente
Os dados não atualizam automaticamente. Não há lógica condicional (if/else) baseada nos valores gerados.		 Parcial
Usa `setInterval` para atualizar dados, mas as condicionais de alerta falham ou não aplicam mudanças visuais (como animações CSS).		 Pleno
Atualização periódica (`setInterval`) com geração randômica funcional. Condicionais precisas disparam alertas visuais e lógicas de automação (ligar atuadores/logs).
Criação Dinâmica e Log de Eventos Insuficiente
Não implementou o log de eventos dinâmico.		 Parcial
Registra logs, mas não usa `createElement` corretamente (ex: sobrescreve via `innerHTML` de forma insegura/ineficiente) ou não insere a data/hora.		 Pleno
Usa `document.createElement()` e `.prepend()` para criar um histórico em tempo real das ações e automações com timestamp, sem quebrar a interface.

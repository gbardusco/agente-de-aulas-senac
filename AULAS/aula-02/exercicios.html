📝 Lista de Exercícios — Aula 02

Listas, Links, Imagens, Tabelas e Semântica HTML

📅 15/07/2026 ⏱ 60 minutos 📂 6 exercícios
1
Catálogo de Sensores IoT Básico

Crie uma página "Catálogo de Sensores IoT" com pelo menos 3 sensores. Para cada sensor, inclua:

  • Uma imagem (<img>) — pode ser um placeholder usando https://loremflickr.com/1000/1000/nomedosensor
  • O nome do sensor como subtítulo (<h2>)
  • Uma lista não ordenada (<ul>) com 3 características
  • Um link (<a>) para "saber mais" (pode apontar para qualquer site real de eletrônica)
💡 Dica: Use width="250" na tag <img> para controlar o tamanho da imagem. Não esqueça do atributo alt!
2
Tabela Comparativa de Sensores Básico

Crie uma página com uma tabela HTML que compare pelo menos 4 sensores. A tabela deve ter as seguintes colunas:

  • Nome do Sensor
  • Tipo (Temperatura, Umidade, Luminosidade, Distância...)
  • Alimentação (ex: 3.3V, 5V)
  • Preço Médio (ex: R$ 12,00)

Use <thead> para o cabeçalho e <tbody> para os dados. Os cabeçalhos devem usar <th>.

💡 Dica: Pesquise os sensores que vocês conhecem das aulas de eletrônica (DHT11, LDR, HC-SR04, BMP280...) e preencha com dados reais!
3
Mini-site Smart Home (Semântico) Intermediário

Crie uma página com estrutura semântica (<header>, <main>, <footer>) que apresente um "mini-site" sobre Smart Homes. O <main> deve ter pelo menos 2 seções (<section>):

  • Seção 1: "O que é uma Smart Home?" — com parágrafo explicativo e uma lista ordenada (<ol>) com os passos para montar uma
  • Seção 2: "Dispositivos Essenciais" — com uma lista não ordenada de pelo menos 4 dispositivos, cada um com uma breve descrição

O <header> deve ter o título do site e o <footer> deve conter um link e informações de crédito.

💡 Dica: Lembre-se que <header>, <main>, <section> e <footer> funcionam como "caixas organizadoras" — o visual ainda é parecido, mas a estrutura fica muito melhor para navegadores e buscadores.
4
Ficha Técnica do ESP32 Intermediário

Crie uma página que funcione como uma "Ficha Técnica" completa do ESP32, contendo:

  • Um <header> com o título "Ficha Técnica — ESP32" e uma imagem do microcontrolador
  • Uma <section> de "Especificações" com uma tabela contendo: Processador, Frequência, Memória RAM, Wi-Fi, Bluetooth, Pinos GPIO
  • Uma <section> de "Projetos Possíveis" com uma lista ordenada de 5 projetos IoT que podem ser feitos com o ESP32
  • Um <footer> com um link externo para o site oficial da Espressif (target="_blank")
💡 Dica: Este exercício combina tudo que aprendemos hoje — listas, tabelas, imagens, links e semântica. Pense nele como uma página de datasheet que a gente vê quando pesquisa componentes eletrônicos.
⭐ Desafios
5
Site de 2 Páginas Interligadas Desafio

Crie um site com 2 páginas HTML que se linkam entre si:

  • home.html — página inicial com: título, parágrafo de boas-vindas, imagem, lista de destaques e link para a segunda página
  • sobre.html — página "Sobre" com: informações sobre o projeto, uma lista de tecnologias usadas e um link para voltar à Home

Ambas as páginas devem usar a estrutura semântica completa: <header>, <main> e <footer>.

💡 Dica: Para linkar entre as páginas, basta usar <a href="sobre.html">Sobre</a> (sem caminho completo, pois estão na mesma pasta). Salve os dois arquivos na mesma pasta!
6
Portal IoT com Navegação e 3 Páginas Desafio

Evolua o exercício anterior! Crie um portal com 3 páginas interligadas:

  • index.html — página principal com uma introdução ao mundo IoT e imagens
  • sensores.html — página com uma tabela comparativa de pelo menos 5 sensores (nome, tipo, tensão, preço, link de compra)
  • contato.html — página simples com informações de contato e um link de e-mail (mailto:)

Todas as páginas devem conter um menu de navegação usando a tag <nav> dentro do <header>, com links para as 3 páginas. Assim o usuário pode navegar entre qualquer página sem usar o botão "Voltar" do navegador.

💡 Dica: O menu de navegação é simplesmente uma lista de links dentro de <nav>:
<nav><ul><li><a href="index.html">Início</a></li> ...</ul></nav>

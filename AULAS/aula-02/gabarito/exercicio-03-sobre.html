Sobre o IoT Lab

Nossa Missão

O IoT Lab nasceu como um projeto educacional do curso de Internet das Coisas do Senac SP. Nosso objetivo é democratizar o acesso ao conhecimento sobre dispositivos conectados, sensores e automação, tornando a tecnologia acessível a todos.

Acreditamos que a melhor forma de aprender é praticando. Por isso, todos os nossos projetos são pensados para serem replicados com componentes acessíveis e de baixo custo.

Tecnologias Utilizadas

  • Arduino — prototipagem rápida e aprendizado de eletrônica
  • ESP32 — microcontrolador com Wi-Fi e Bluetooth integrados
  • HTML, CSS e JavaScript — desenvolvimento de interfaces web para dashboards
  • MQTT — protocolo de comunicação leve para IoT
  • Python — processamento de dados e automação

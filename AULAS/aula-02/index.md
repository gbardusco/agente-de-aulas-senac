# Aula 02 — Listas, Links, Imagens, Tabelas e Semântica HTML

**Data:** 15/07/2026 (Quarta-feira)  
**Horário:** 19h00 às 22h30  

## Conteúdo

- Listas ordenadas (`<ol>`) e não ordenadas (`<ul>`, `<li>`)
- Links (`<a href="">`) — navegação entre páginas locais e externas
- Imagens (`<img src="" alt="">`) — inserção de imagens locais
- **Tabelas HTML** (`<table>`, `<tr>`, `<th>`, `<td>`) — organização de dados tabulares
- Tags semânticas: `<header>`, `<main>`, `<section>`, `<footer>`, `<nav>`

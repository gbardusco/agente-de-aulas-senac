Parte 1

Listas HTML

📋 Lista Não Ordenada — <ul>

<ul>
    <li>Sensor de temperatura</li>
    <li>Sensor de umidade</li>
    <li>Sensor de luminosidade</li>
</ul>
Resultado no navegador
  • Sensor de temperatura
  • Sensor de umidade
  • Sensor de luminosidade

<ul> = Unordered List (lista com bolinhas)

🔢 Lista Ordenada — <ol>

<ol>
    <li>Coleta de dados (sensor)</li>
    <li>Transmissão (Wi-Fi/LoRa)</li>
    <li>Processamento (nuvem)</li>
    <li>Visualização (dashboard)</li>
</ol>
Resultado no navegador
  1. Coleta de dados (sensor)
  2. Transmissão (Wi-Fi/LoRa)
  3. Processamento (nuvem)
  4. Visualização (dashboard)

<ol> = Ordered List (lista numerada). Cada item é um <li> (List Item).

Parte 2

Links

🔗 Links — <a>

<!-- Link para um site externo -->
<a href="https://www.arduino.cc">Site do Arduino</a>

<!-- Link para outra página local -->
<a href="sobre.html">Ir para a página Sobre</a>

<!-- Link que abre em nova aba -->
<a href="https://www.espressif.com" target="_blank">ESP32</a>

href = destino do link
target="_blank" = abre em nova aba

⚠️ <a> vem de anchor (âncora). O texto entre as tags é o que aparece clicável na tela.

Parte 3

Imagens

🖼️ Imagens — <img>

<!-- Imagem local (na mesma pasta) -->
<img src="sensor-dht11.jpg" alt="Foto do sensor DHT11">

<!-- Imagem em subpasta -->
<img src="imagens/arduino.png" alt="Placa Arduino Uno">

<!-- Imagem com tamanho definido -->
<img src="esp32.jpg" alt="ESP32" width="300">

src = caminho da imagem
alt = texto alternativo (acessibilidade)
width = largura em pixels

💡 A tag <img> é auto-fechada — não tem </img>!

Parte 4

Tabelas HTML

📊 Tabelas — <table>

<table>
    <thead>
        <tr>
            <th>Sensor</th>
            <th>Preço</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>DHT11</td>
            <td>R$ 12</td>
        </tr>
    </tbody>
</table>
Resultado no navegador
Sensor Preço
DHT11 R$ 12

💡 <th> = cabeçalho (negrito)
<td> = dado (célula)
<tr> = linha

Parte 5

HTML Semântico

🏗️ Tags Semânticas

Dão significado à estrutura da página — o navegador e os buscadores entendem o que cada parte é.

<header>
    <h1>Meu Site IoT</h1>
</header>

<main>
    <section>
        <h2>Sensores</h2>
        <p>Conteúdo...</p>
    </section>
</main>

<footer>
    <p>© 2026</p>
</footer>
TagRepresenta
<header>Cabeçalho da página
<main>Conteúdo principal
<section>Seção temática
<footer>Rodapé da página
<nav>Navegação

❌ vs ✅ — Estrutura Semântica

❌ Sem semântica
<div>
    <h1>Título</h1>
</div>
<div>
    <p>Conteúdo</p>
</div>
<div>
    <p>Rodapé</p>
</div>
✅ Com semântica
<header>
    <h1>Título</h1>
</header>
<main>
    <p>Conteúdo</p>
</main>
<footer>
    <p>Rodapé</p>
</footer>

Mão na Massa

🖥️ Live Coding

✅ O que aprendemos hoje

  • <ul> e <ol> criam listas (cada item é um <li>)
  • <a href="..."> cria links para outras páginas
  • <img src="..." alt="..."> insere imagens
  • <table> organiza dados em linhas e colunas (<tr>, <th>, <td>)
  • Tags semânticas (<header>, <main>, <section>, <footer>) dão significado à estrutura

📝 Lista de Exercícios — Aula 13

Alertas Visuais e Lógica de Automação

📅 25/08/2026⏱ 45 min📂 3 exercícios
1
Alerta Visual com AnimaçãoBásico

No seu Dashboard, implemente: se a temperatura ultrapassar 35°C, o card deve piscar com animação CSS (@keyframes) e exibir o emoji ⚠️ ao lado do valor.

💡 Dica: Crie uma classe CSS .alerta com animation: piscar 1s infinite e adicione/remova via JS com classList.add() e classList.remove().
2
Automação CruzadaIntermediário

Crie uma regra de automação: se a luminosidade cair abaixo de 200 lux, o card de "Iluminação" deve mudar automaticamente de "Desligada" para "Ligada" (mudando cor e texto).

⭐ Desafio
3
Log de EventosDesafio

Adicione um "log de eventos" no rodapé da dashboard: cada vez que um alerta disparar ou uma automação agir, adicione uma linha de texto com o horário e a descrição do evento.

💡 Dica: Use document.createElement("p") para criar novos parágrafos e container.prepend(elemento) para adicioná-los no topo da lista.

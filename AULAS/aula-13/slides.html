🚨 Alertas Visuais: Animação CSS

Usamos @keyframes no CSS para criar uma animação (ex: piscar), e o JavaScript para ativá-la adicionando a classe.

CSS

@keyframes piscar {
  0%, 100% { opacity: 1; }
  50% { opacity: 0.3; }
}

.alerta-ativo {
  animation: piscar 1s infinite;
  border-color: red;
}

JavaScript

let card = document.getElementById("card-temp");

if (temp > 35) {
    card.classList.add("alerta-ativo");
} else {
    card.classList.remove("alerta-ativo");
}

🤖 Lógica de Automação

A automação ocorre quando o estado de um sensor altera o estado de um atuador automaticamente.

// Se a temperatura subir muito, liga o ventilador!
if (temperatura > 35) {
    let ventilador = document.getElementById("ventilador");
    
    // Só liga se já não estiver ligado
    if (!ventilador.classList.contains("ligado")) {
        ventilador.classList.add("ligado");
        adicionarNoLog("Ventilador ligado automaticamente.");
    }
}

📋 Log de Eventos Dinâmico

Como adicionar novos elementos HTML na página usando JS:

function adicionarLog(mensagem) {
    let caixaLog = document.getElementById("meu-log");
    
    // 1. Cria um novo parágrafo
    let novoParagrafo = document.createElement("p");
    
    // 2. Define o texto dele
    novoParagrafo.textContent = mensagem;
    
    // 3. Insere na caixa de logs (prepend = no topo)
    caixaLog.prepend(novoParagrafo);
}

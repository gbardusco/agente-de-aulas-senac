🖱️ O que são Eventos?

Eventos são ações do usuário que o navegador detecta:

EventoQuando dispara
clickUsuário clica em um elemento
inputValor de um campo muda
submitFormulário é enviado
mouseoverMouse passa por cima
keydownTecla é pressionada

🔘 Funções em JavaScript

// Definindo uma função
function ligarSensor() {
    console.log("Sensor ligado!");
}

// Chamando a função
ligarSensor();

// Função com parâmetro
function saudacao(nome) {
    alert("Olá, " + nome + "!");
}
saudacao("Maria");

🔗 Conectando Evento ao Botão

Forma 1: onclick no HTML

<button onclick="ligar()">
  Ligar
</button>

Forma 2: addEventListener ✅

let btn = document.getElementById("btn");

btn.addEventListener("click", function() {
    console.log("Clicado!");
});

💡 addEventListener é a forma recomendada — separa HTML do JS!

📥 Capturando Valores de Input

<input type="text" id="campo-nome">
<button id="btn-saudar">Saudar</button>
<p id="resultado"></p>
let btn = document.getElementById("btn-saudar");

btn.addEventListener("click", function() {
    let nome = document.getElementById("campo-nome").value;
    document.getElementById("resultado").textContent = "Olá, " + nome + "!";
});

💡 Exemplo: Lâmpada IoT

let lampada = document.getElementById("lampada");
let btnLigar = document.getElementById("btn-ligar");
let btnDesligar = document.getElementById("btn-desligar");

btnLigar.addEventListener("click", function() {
    lampada.style.backgroundColor = "#fbbf24"; // amarelo
    lampada.textContent = "💡 LIGADA";
});

btnDesligar.addEventListener("click", function() {
    lampada.style.backgroundColor = "#333";    // cinza
    lampada.textContent = "⚫ DESLIGADA";
});

✅ O que aprendemos hoje

  • Eventos são ações que o navegador detecta (click, input...)
  • Funções agrupam código reutilizável
  • addEventListener("click", função) conecta evento ao botão
  • .value captura o que o usuário digitou no input
  • Combinando eventos + DOM + condicionais = interatividade!

JavaScript: Primeiros Passos

📅 11/08/2026 ⏱ 45 minutos 📂 4 exercícios
1
Saudação Personalizada Básico

Crie uma página HTML + JS que, ao ser aberta:

  • Pergunte o nome do usuário usando prompt()
  • Exiba uma saudação personalizada usando alert(), ex: "Olá, Maria! Bem-vinda ao painel IoT!"
💡 Dica: Use + para juntar (concatenar) strings: "Olá, " + nome + "!"
2
Calculadora Básica Básico

Crie um programa que:

  • Peça dois números via prompt()
  • Calcule a soma, subtração, multiplicação e divisão
  • Mostre todos os resultados no console.log()
💡 Dica: prompt() retorna texto (string). Use Number(valor) para converter em número antes de calcular!
3
Conversor Celsius → Fahrenheit Intermediário

Crie um programa que:

  • Pergunte a temperatura em Celsius via prompt()
  • Converta para Fahrenheit usando a fórmula: F = C × 9/5 + 32
  • Exiba o resultado com alert(), ex: "25°C = 77°F"
⭐ Desafio
4
Classificador de Temperatura Desafio

Crie um programa que pergunte a temperatura de um sensor e classifique:

  • Abaixo de 15°C → "Frio ❄️"
  • Entre 15°C e 30°C → "Normal ✅"
  • Acima de 30°C → "Alerta! 🔥"

Exiba o resultado com alert(). Você precisará usar if/else — pode pesquisar!

💡 Dica: A sintaxe do if/else é: if (condição) { ... } else if (condição) { ... } else { ... }

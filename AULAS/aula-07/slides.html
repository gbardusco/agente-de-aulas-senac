🔧 Console do Navegador

O console é sua ferramenta de testes para JavaScript:

  1. Abra o Chrome → F12 (ou botão direito → Inspecionar)
  2. Clique na aba Console
  3. Digite e aperte Enter:
console.log("Olá, mundo!");
console.log(2 + 3);
console.log("Temperatura: " + 25 + "°C");

💡 console.log() é como um "print" — mostra valores no console para você testar e debugar.

➕ Operadores

Aritméticos

let a = 10, b = 3;

a + b   // 13 (soma)
a - b   // 7  (subtração)
a * b   // 30 (multiplicação)
a / b   // 3.33 (divisão)
a % b   // 1  (resto)

Comparação

10 === 10  // true (igual)
10 !== 5   // true (diferente)
10 > 5    // true (maior)
10 < 5    // false (menor)
10 >= 10  // true (maior ou igual)

⚠️ Use === (três iguais) para comparar! Dois iguais (==) pode gerar resultados inesperados.

💬 alert() e prompt()

// Mostra uma mensagem na tela
alert("Bem-vindo ao Painel IoT!");

// Pergunta algo ao usuário e guarda a resposta
let nome = prompt("Qual é o seu nome?");
alert("Olá, " + nome + "!");

⚠️ prompt() sempre retorna uma string. Para converter para número, use Number(valor).

📎 Vinculando JS ao HTML

<!DOCTYPE html>
<html>
<head>
    <title>Minha página</title>
</head>
<body>
    <h1>Olá!</h1>

    <!-- O JS deve ficar ANTES de fechar o body -->
    <script src="script.js"></script>
</body>
</html>

💡 Coloque o <script> no final do <body> para garantir que o HTML já foi carregado!

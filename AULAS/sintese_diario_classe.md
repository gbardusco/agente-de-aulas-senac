# Síntese do Diário de Classe — Relacionamento com Indicadores da UC14

Este documento serve como apoio metodológico e técnico para a redação do **Diário de Classe**. Ele mapeia as 15 aulas planejadas aos indicadores da UC14 presentes no Plano de Curso, oferecendo textos adequados às diretrizes do Senac Solution (focados em clareza, objetividade e descrição de fatos observáveis).

## Módulo 1: Fundamentos Web e Portfólio (Aulas 01 a 06)

O foco deste primeiro bloco é o desenvolvimento de interfaces estáticas utilizando HTML e CSS, além da familiarização com o ambiente de edição de código e navegador.

### Indicadores Atingidos:
- **Indicador 1 e 4:** Configura e elabora código voltado a dispositivos móveis (Introdução ao Design Responsivo e Media Queries).
- **Indicador 2:** Configura o ambiente de desenvolvimento conforme as funcionalidades e características do aplicativo computacional para acesso via web.
- **Indicador 3:** Desenvolve softwares de acordo com a linguagem de programação selecionada. *(HTML e CSS)*
- **Indicador 5:** Elabora código conforme as funcionalidades e características do aplicativo computacional para web.

### Sugestões de Registro de Chamada (Atividades Desenvolvidas):
- **Aula 01:** "Exposição dialogada sobre o funcionamento da Web e estruturação semântica de páginas HTML, apresentando as tags fundamentais e o ambiente de desenvolvimento local."
- **Aula 02:** "Atividade prática sobre semântica HTML, abordando listas, inserção de imagens e links hipertexto, visando a construção de uma página de catálogo de sensores."
- **Aula 03:** "Apresentação e prática introdutória de CSS, com aplicação de estilos básicos, cores e propriedades de tipografia no HTML construído anteriormente."
- **Aula 04:** "Prática de layout de páginas web com a utilização do CSS Flexbox, objetivando a organização, distribuição e alinhamento responsivo dos elementos em tela."
- **Aula 05:** "Desenvolvimento prático de formulários HTML integrados à estilização CSS e introdução ao CSS Responsivo (Media Queries), com foco na adaptação da interface para telas de dispositivos móveis."
- **Aula 06:** "Construção guiada do primeiro projeto avaliativo (Portfólio Pessoal), mobilizando os conhecimentos de HTML semântico e CSS Flexbox trabalhados nas aulas anteriores."

### Sugestões de Registro de Indicador (Avaliação Parcial/Final):
*Exemplo de registro positivo para os indicadores 3 e 5:*
> "Aluno configurou adequadamente o ambiente e elaborou código HTML/CSS válido. Desenvolveu a página de Portfólio Pessoal aplicando corretamente a estruturação semântica e o layout via Flexbox, demonstrando avanço na construção de interfaces web."

## Módulo 2: Interatividade e Dashboard IoT (Aulas 07 a 15)

Este bloco introduz o **JavaScript**, sempre relacionando a lógica do Front-End ao contexto de equipamentos e sensores (condicionais para alertas, temporizadores para atualização de leituras).

### Indicadores Atingidos:
- **Indicador 1 e 4:** Configura e elabora código para dispositivos móveis (Configuração do manifesto PWA e layout adaptável).
- **Indicador 3:** Desenvolve softwares de acordo com a linguagem de programação selecionada. *(JavaScript)*
- **Indicador 5:** Elabora código conforme as funcionalidades e características do aplicativo computacional para web.
- **Indicador 6:** Realiza a compilação e depuração do código desenvolvido de acordo com orientações técnicas da IDE utilizada. *(Uso do Console do Navegador)*
- **Indicador 7:** Utiliza comandos de integração de bancos de dados/servidor de rede (Fundamentos de consumo de API via `fetch()` e dados remotos JSON).

### Sugestões de Registro de Chamada (Atividades Desenvolvidas):
- **Aula 07:** "Introdução à linguagem JavaScript, englobando declaração de variáveis, operadores e interação básica via console do navegador, com foco em testes iniciais da sintaxe."
- **Aula 08:** "Prática com estruturas condicionais (if/else) e manipulação do DOM, objetivando alterar textos e estilos da página dinamicamente com base em variáveis que simulam sensores."
- **Aula 09:** "Aplicação de Eventos (listeners) no JavaScript e criação de funções, visando tornar a interface reativa a ações do usuário, como simular a ativação e desativação de atuadores."
- **Aula 10:** "Prática de estruturação de loops (for) e funções parametrizadas, focada na geração aleatória e atualização massiva de múltiplos dados de sensores em tela."
- **Aula 11:** "Implementação de temporizadores (setInterval), com o objetivo de criar um fluxo de atualização contínua e em tempo real para os dados do painel."
- **Aula 12:** "Estruturação visual do wireframe do Dashboard IoT utilizando HTML e CSS, preparando a fundação da interface para integração com a lógica JavaScript."
- **Aula 13:** "Desenvolvimento de lógicas de automação e alertas visuais no painel, utilizando manipulação de DOM e animações CSS para criar feedbacks imediatos em estados críticos dos sensores simulados."
- **Aula 14:** "Introdução ao consumo de APIs utilizando a função fetch() e o formato JSON, conectando o Dashboard IoT a dados reais da rede, além de preparação técnica do projeto final como um Progressive Web App (PWA)."
- **Aula 15:** "Apresentação técnica dos projetos finais (Dashboard IoT) desenvolvidos pelos alunos, acompanhada de roda de conversa para feedback e encerramento da unidade curricular."

### Sugestões de Registro de Indicador (Avaliação Parcial/Final):
*Exemplo de registro positivo para os indicadores 3, 5 e 6:*
> "Aluno elaborou e depurou código JavaScript para o Dashboard IoT, utilizando corretamente os eventos, loops e condicionais propostos. Implementou atualizações periódicas e lógicas de alerta na interface de forma funcional e sem erros no console, atingindo o desempenho esperado no projeto."

*Exemplo de registro de necessidade de feedback (Indicador 6):*
> "Aluno desenvolveu a lógica central do Dashboard, mas apresentou dificuldade inicial na identificação e correção de erros (depuração) utilizando o console do navegador, necessitando de mediação para corrigir falhas de sintaxe na manipulação de eventos."

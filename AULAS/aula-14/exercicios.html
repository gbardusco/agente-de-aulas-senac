📅 26/08/2026 ⏱ 45 minutos 📂 2 exercícios
1
Buscador de Personagens (Star Wars API) Intermediário

Vamos usar a API pública do Star Wars (SWAPI).

1. Crie uma página com um botão "Buscar Luke Skywalker".

2. Ao clicar, use o fetch() na URL: https://swapi.dev/api/people/1/

3. Pegue a resposta, converta para .json() e exiba o nome e a cor do cabelo do personagem em elementos HTML (ex: <span>).

2
Integração API no Dashboard IoT Desafio

No seu projeto final (Dashboard IoT), você usava Math.random() para gerar a Temperatura. Vamos trocar isso!

Use a API pública de clima (ou uma API mockada que o professor passar) para buscar a temperatura real e atualizá-la no seu painel a cada 10 segundos.

Dica: Substitua a lógica de gerar o número aleatório pela chamada do fetch() e coloque a alteração do textContent dentro do .then().

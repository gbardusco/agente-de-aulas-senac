🌍 O que é uma API?

Application Programming Interface (Interface de Programação de Aplicação).

É como um "garçom" de restaurante:

  1. Você (o Front-End) faz o pedido (Requisição).
  2. A API leva o pedido para a cozinha (Banco de Dados/Back-End).
  3. A API te traz o prato pronto (Resposta com os dados).

Em IoT, usamos APIs para pegar dados de servidores meteorológicos, enviar leitura de sensores ou acessar Bancos de Dados remotos!

📦 O Formato JSON

O JavaScript Object Notation é o formato de texto mais usado pelas APIs para enviar dados.

{
  "cidade": "São Paulo",
  "temperatura": 25.5,
  "umidade": 60,
  "sensores_ativos": true
}

Parece muito com objetos do próprio JavaScript, facilitando a nossa vida na hora de ler os dados.

🐶 Buscando dados com fetch()

A função fetch() faz uma requisição pela rede. Como a internet pode demorar, usamos as chamadas Promises (Promessas) com os métodos .then().

fetch('https://api.exemplo.com/clima')
    .then(resposta => resposta.json()) // 1. Converte a resposta pra JSON
    .then(dados => { 
        // 2. Usa os dados de verdade
        console.log("A temperatura é: " + dados.temperatura);
        document.getElementById('v-temp').textContent = dados.temperatura;
    })
    .catch(erro => console.error("Deu erro!", erro)); // 3. Se a internet cair

📅 12/08/2026⏱ 45 min📂 3 exercícios
1
Status do SensorBásico

Crie uma página com um parágrafo que diz "Status do Sensor". No JavaScript:

  • Defina uma variável temperatura com um valor
  • Se temperatura > 30: mude o texto para "🔴 ALERTA: Temperatura Alta!" com fundo vermelho
  • Senão: mude para "🟢 Normal" com fundo verde

Use document.getElementById(), .textContent e .style.

2
3 Sensores com CondicionaisIntermediário

Crie uma página com 3 <div> representando 3 sensores. Defina 3 variáveis de temperatura no JS e, para cada uma, mude o texto e a cor de fundo da div correspondente usando condicionais.

⭐ Desafio
3
Verificador de Senha VisualDesafio

Crie uma página com um parágrafo que mostra a "força" de uma senha. Defina uma variável senha (string) no JS:

  • Menos de 6 caracteres → "Senha fraca" em vermelho
  • Entre 6 e 10 → "Senha média" em amarelo
  • Acima de 10 → "Senha forte" em verde
💡 Dica: Use senha.length para saber o número de caracteres de uma string.

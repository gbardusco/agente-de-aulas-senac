🔀 Condicionais: if / else

let temperatura = 35;

if (temperatura > 30) {
    console.log("🔥 Alerta! Temperatura alta!");
} else if (temperatura >= 15) {
    console.log("✅ Temperatura normal.");
} else {
    console.log("❄️ Temperatura baixa!");
}

O programa testa cada condição de cima para baixo e executa apenas o primeiro bloco que for verdadeiro.

Parte 2

Manipulação do DOM

🌳 O que é o DOM?

Document Object Model — é como o navegador "enxerga" o HTML: uma árvore de objetos que o JavaScript pode ler e modificar.

// Selecionar um elemento pelo ID
let titulo = document.getElementById("meu-titulo");

// Alterar o texto
titulo.textContent = "Novo texto!";

// Alterar o estilo
titulo.style.color = "red";
titulo.style.backgroundColor = "#1a1a2e";

🎯 Exemplo Prático: Painel de Sensor

HTML

<p id="status">Carregando...</p>

JavaScript

let temp = 35;
let el = document.getElementById("status");

if (temp > 30) {
    el.textContent = "🔴 ALERTA!";
    el.style.color = "red";
} else {
    el.textContent = "🟢 Normal";
    el.style.color = "green";
}

🎯 Isso é o core do Dashboard IoT!

Ler dados → avaliar condição → mudar o que aparece na tela.

📝 Lista de Exercícios — Aula 01

O que é a Web e Estrutura HTML

📅 14/07/2026 ⏱ 45 minutos 📂 3 exercícios + 1 desafio
1
Página de Apresentação Pessoal Básico

Crie uma página HTML que contenha:

  • Um título principal (<h1>) com o seu nome
  • Um subtítulo (<h2>) com sua área de interesse em IoT
  • Dois parágrafos (<p>): um sobre por que escolheu o curso e outro sobre o que espera aprender
💡 Dica: Não esqueça da estrutura básica: <!DOCTYPE html>, <html>, <head>, <body>. Coloque um <title> descritivo na aba do navegador.
2
Ficha Técnica de um Sensor Intermediário

Crie uma segunda página HTML que simule uma "ficha técnica" de um sensor IoT à sua escolha (ex: DHT11, LDR, HC-SR04, etc.). A página deve conter:

  • O nome do sensor como título principal (<h1>)
  • 3 subtítulos (<h2>): Descrição, Aplicações, Especificações
  • Um parágrafo (<p>) abaixo de cada subtítulo explicando o conteúdo
  • Use <hr> para separar as seções visualmente
💡 Dica: Pesquise rapidamente o sensor escolhido para escrever informações reais. Não precisa ser perfeito — o importante é praticar a estrutura HTML.
⭐ Desafio
3
3 Projetos IoT Interessantes Desafio

Crie uma página que apresente 3 projetos IoT que você acha interessantes. Para cada projeto:

  • Coloque o nome do projeto como subtítulo (<h2>)
  • Escreva uma descrição em parágrafo (<p>) explicando o que o projeto faz
  • Adicione um subtítulo menor (<h3>) chamado "Por que é interessante?" com mais um parágrafo

Use <hr> entre os projetos para separação visual e inclua um <h1> geral no topo da página.

💡 Dica: Pense em projetos que envolvam automação residencial, saúde, agricultura, transporte, ou qualquer área que te interesse!

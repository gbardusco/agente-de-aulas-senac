🌐 O que é a Web?

A World Wide Web é um sistema de documentos interligados que funcionam sobre a Internet.

Quando você acessa um site, o navegador faz 3 coisas:

  1. Pede o arquivo ao servidor
  2. Recebe o código (HTML, CSS, JS)
  3. Interpreta e mostra na tela
💻

Navegador = Interpretador

O navegador lê o código HTML e desenha a página. É como uma receita: o HTML são os ingredientes e as instruções.

🔗 Web + IoT: Por que isso importa?

Na Internet das Coisas, os dispositivos precisam de interfaces visuais para:

  • 📊 Dashboards — monitorar sensores em tempo real
  • 🎛️ Painéis de controle — ligar/desligar atuadores
  • 📱 Apps web — acessar de qualquer dispositivo
  • ⚠️ Alertas visuais — avisar sobre anomalias

Tudo isso roda no navegador!

HTML + CSS + JavaScript são as tecnologias que constroem essas interfaces. É isso que vamos aprender.

Parte 1

O que é HTML?

📝 HTML — HyperText Markup Language

Linguagem de Marcação de Hipertexto — não é uma linguagem de programação, é uma linguagem de marcação.

🏗️ Marcação

Usamos tags (etiquetas) para dizer ao navegador o que cada parte do conteúdo é: um título, um parágrafo, uma imagem...

🔗 Hipertexto

Textos que se conectam a outros textos através de links. É o que permite navegar de uma página para outra.

🏷️ Anatomia de uma Tag HTML

<h1>Meu Primeiro Título</h1>
  • <h1> → Tag de abertura
  • </h1> → Tag de fechamento (com /)
  • O texto entre as tags → Conteúdo

⚠️ Cuidado! Esquecer de fechar uma tag é um dos erros mais comuns. Sempre que abrir, feche!

📄 Estrutura Básica de um Documento HTML

<!DOCTYPE html>
<html lang="pt-BR">
<head>
    <meta charset="UTF-8">
    <title>Minha Primeira Página</title>
</head>
<body>
    <h1>Olá, Mundo!</h1>
    <p>Minha primeira página web.</p>
</body>
</html>

🔍 Entendendo Cada Parte

ElementoO que faz
<!DOCTYPE html>Diz ao navegador: "isso é HTML5"
<html lang="pt-BR">Início do documento, idioma em português
<head>Informações sobre a página (não aparece na tela)
<meta charset="UTF-8">Permite acentos e caracteres especiais (ç, ã, é)
<title>Título na aba do navegador
<body>Tudo que aparece na tela fica aqui

Parte 2

Tags Essenciais

📐 Títulos: <h1> a <h6>

<h1>Título Principal</h1>
<h2>Subtítulo</h2>
<h3>Sub-subtítulo</h3>
<h4>Nível 4</h4>
<h5>Nível 5</h5>
<h6>Nível 6</h6>

📌 Hierarquia importa!

<h1> é o mais importante (maior).
<h6> é o menos importante (menor).

Use apenas um <h1> por página!

📝 Parágrafos e Quebras

Parágrafo <p>

<p>Este é um parágrafo.
   O navegador ignora
   quebras de linha no código.</p>

<p>Este é outro parágrafo.</p>

Quebra de Linha <br>

<p>Linha 1<br>
Linha 2<br>
Linha 3</p>

Linha Horizontal <hr>

<p>Seção 1</p>
<hr>
<p>Seção 2</p>

💡 <br> e <hr> são tags que não precisam de fechamento (tags "auto-fechadas").

📝 Lista de Exercícios — Aula 05

Formulários HTML + Estilização CSS

📅 05/08/2026 ⏱ 45 minutos 📂 3 exercícios
1
Formulário de Configuração de Sensor Básico

Crie um formulário de "Configuração de Sensor" com os seguintes campos:

  • Nome do sensor — input text
  • Tipo de sensor — select com opções (Temperatura, Umidade, Luminosidade, Pressão)
  • Leitura mínima e máxima — input number
  • Intervalo de coleta — input range (1 a 60 segundos)
  • Um botão "Salvar Configuração"

Estilize todo o formulário com CSS externo: fundo escuro, bordas, padding, e efeito :focus nos campos.

2
Formulário de Contato para Portfólio Intermediário

Crie um formulário de "Contato" que será usado no seu portfólio, contendo:

  • Nome — input text com required
  • E-mail — input email com required
  • Assunto — select (Dúvida, Proposta, Feedback, Outro)
  • Mensagem — textarea com 5 linhas
  • Botão "Enviar Mensagem"

Use :hover no botão e :focus nos campos para dar feedback visual ao usuário.

⭐ Desafio
3
Página de Login Completa Desafio

Crie uma página de "Login" completa e estilizada:

  • Campo de e-mail e senha
  • Botão "Entrar"
  • Link "Esqueci a senha"
  • Link "Criar conta"

A caixa de login deve estar centralizada na tela (use Flexbox no body). Estilize com tema escuro, bordas arredondadas e efeitos visuais.

Requisito Mobile: Use @media (max-width: 768px) para que, em telas de celular, a caixa de login se adapte e ocupe praticamente toda a largura da tela (removendo margens laterais excessivas).

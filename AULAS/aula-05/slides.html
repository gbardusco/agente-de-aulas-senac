Aula 05 · 05 de agosto de 2026

📋 Por que Formulários?

Formulários são a principal forma de coletar dados do usuário na web:

  • 🔐 Telas de login
  • 📝 Cadastros
  • 🔍 Campos de busca
  • ⚙️ Configurações de dispositivos IoT
  • 📊 Filtros de dashboard

Em IoT, formulários são usados para configurar sensores, definir intervalos de leitura, e cadastrar dispositivos no sistema.

🏷️ Estrutura Básica de um Formulário

<form>
    <label for="nome">Nome:</label>
    <input type="text" id="nome" placeholder="Digite seu nome">

    <label for="email">E-mail:</label>
    <input type="email" id="email" placeholder="seu@email.com" required>

    <button type="submit">Enviar</button>
</form>

💡 <label for="id"> conecta o rótulo ao campo — clicando no label, o campo ganha foco!

TipoAparênciaUso em IoT

📦 <select> e <textarea>

Dropdown (seleção)

<select id="tipo">
    <option value="">Selecione</option>
    <option value="temp">Temperatura</option>
    <option value="umid">Umidade</option>
    <option value="luz">Luminosidade</option>
</select>

Área de texto

<textarea id="obs"
    rows="4"
    placeholder="Observações...">
</textarea>

🎨 Estilizando Formulários com CSS

input, select, textarea {
    width: 100%;
    padding: 12px;
    border: 2px solid #333;
    border-radius: 8px;
    background: #1a1a3e;
    color: #f0f0f0;
    font-size: 16px;
}

input:focus, select:focus, textarea:focus {
    border-color: #00d4ff;
    outline: none;     /* remove borda padrão */
}

button {
    background: #00d4ff;
    color: #000;
    border: none;
    padding: 12px 24px;
    border-radius: 8px;
    cursor: pointer;
}

button:hover {
    background: #00b8e6;
}

CSS Responsivo (Mobile)

📱 Por que ser Responsivo?

O layout do site deve se adaptar automaticamente ao tamanho da tela (celular, tablet, desktop).

Em projetos de IoT, a maioria dos usuários acessará o Dashboard através do Smartphone para checar a casa remotamente.

💡 Dica de Ouro: Sempre adicione a meta tag de viewport no <head> do HTML:

<meta name="viewport" content="width=device-width, initial-scale=1.0">

📏 Media Queries (@media)

O CSS pode aplicar estilos condicionais dependendo do tamanho da tela.

/* Estilo padrão (telas grandes / desktop) */
.container {
    display: flex;
    flex-direction: row; /* lado a lado */
}

/* Aplicado apenas em telas MENORES que 768px (Celulares) */
@media (max-width: 768px) {
    .container {
        flex-direction: column; /* um embaixo do outro */
    }
}

🖥️ Live Coding

✅ O que aprendemos hoje

  • <form> agrupa campos de entrada
  • <input> tem vários tipos: text, number, email, password, range, checkbox, radio
  • <select> cria dropdowns, <textarea> cria campos de texto grande
  • <label for="..."> conecta rótulo ao campo
  • CSS :focus e :hover estilizam interações.
  • Media Queries (`@media`) alteram o layout para telas pequenas.
  • Flex-direction: column é o melhor amigo do layout mobile!

Git e GitHub

Qual a diferença?

Git (Local)

O software instalado no seu computador. Ele cria uma "linha do tempo" do seu código, registrando cada alteração (versão) para que você não perca nada.

GitHub (Nuvem)

Um site (plataforma) que hospeda os seus projetos gerenciados pelo Git. É como um "Google Drive" específico para programadores.

💡 Passo 1: Crie sua conta gratuita em github.com agora mesmo!

💻 Usando o Terminal

Os desenvolvedores utilizam comandos de texto para controlar o Git. No Windows, usamos o CMD ou PowerShell.


Comandos Básicos de Navegação:

# Listar os arquivos e pastas no diretório atual
> dir

# Entrar em uma pasta chamada "portfolio"
> cd portfolio

# Voltar uma pasta para trás
> cd ..

⚠️ Você precisa navegar até a pasta do seu projeto (`cd Caminho/Para/Seu/Projeto`) antes de usar o Git!

🔄 O Fluxo do Git

# 1. Inicia o monitoramento do Git nesta pasta (fazer só 1 vez)
> git init

# 2. Prepara TODOS os arquivos para serem salvos nesta versão
> git add .

# 3. Salva a versão com uma mensagem descritiva
> git commit -m "Meu primeiro portfolio"

💡 O comando git commit exige que você diga quem você é na primeira vez. Siga as instruções que aparecerem na tela (git config user.email / user.name).

☁️ Subindo para o GitHub (Push)

No site do GitHub, clique no botão New Repository. Depois, copie os 3 últimos comandos que o GitHub fornece e cole no terminal:

# Define a branch principal como "main"
> git branch -M main

# Conecta seu Git local com o repositório na nuvem (link gerado pelo GitHub)
> git remote add origin https://github.com/SEU-USUARIO/SEU-REPOSITORIO.git

# Envia (empurra) o código para a nuvem!
> git push -u origin main

Se pedir login, uma janela do navegador vai abrir para você autorizar o acesso.

🚀 Publicando o Portfólio (Pages)

Agora que seu código está no GitHub, vamos transformá-lo em um site público!

  1. Na página do seu repositório no GitHub, clique em Settings (Configurações) ⚙️.
  2. No menu lateral esquerdo, desça e clique em Pages.
  3. Em Source, selecione a opção Deploy from a branch.
  4. Abaixo, onde diz Branch, mude de "None" para main e clique em Save.
  5. Aguarde alguns minutos, recarregue a página e o link do seu site aparecerá no topo!

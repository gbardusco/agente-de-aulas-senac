📝 Lista de Exercícios — Aula 03

Introdução ao CSS — Cores, Fontes e Box Model

📅 16/07/2026 ⏱ 45 minutos 📂 3 exercícios
1
Cartão de Visita Digital Básico

Crie uma página HTML + CSS que apresente seu "Cartão de Visita Digital". O cartão deve conter:

  • Seu nome (título)
  • Sua foto (ou imagem placeholder)
  • Profissão desejada
  • Informações de contato (e-mail, telefone)

Crie um arquivo CSS externo que aplique:

  • Uma cor de fundo para a página
  • Uma fonte diferente da padrão
  • Cores de texto personalizadas
  • Espaçamento com margin e padding
  • Centralização do conteúdo com text-align: center
2
Catálogo Estilizado Intermediário

Pegue a página "Catálogo de Sensores" que você criou na Aula 02 (ou crie uma nova) e adicione um CSS externo que faça:

  • Mude a cor de fundo da página para um tom escuro
  • Aplique uma fonte diferente (ex: font-family: 'Segoe UI', sans-serif)
  • Coloque bordas arredondadas ao redor de cada sensor (use border e border-radius)
  • Adicione padding e margin para dar espaçamento
  • Use pelo menos uma classe (.classe) para estilizar elementos específicos
💡 Dica: Para bordas arredondadas, use border-radius: 10px. Para bordas completas, use border: 2px solid #cor.
⭐ Desafio
3
Painel IoT Estático Desafio

Crie do zero uma página "Painel IoT" estática (só visual, sem funcionalidade) com 4 "cards" coloridos simulando leituras de sensores:

  • 🌡️ Temperatura: 25°C
  • 💧 Umidade: 60%
  • 💡 Luminosidade: 800 lux
  • 🔊 Ruído: 45 dB

Cada card deve ser uma <div> com uma classe CSS que defina:

  • Cor de fundo diferente para cada card
  • Bordas arredondadas
  • Padding interno
  • Texto centralizado
  • Largura máxima de 300px
  • Margem para separar os cards
💡 Dica: Crie uma classe genérica .card para o estilo base, e classes adicionais como .card-temp, .card-umidade para cores individuais. Um elemento pode ter múltiplas classes: class="card card-temp"

🎨 O que é CSS?

Cascading Style Sheets — Folhas de Estilo em Cascata.

Se o HTML é o esqueleto da página, o CSS é a roupa e maquiagem.

  • 🏗️ HTML = estrutura (o quê)
  • 🎨 CSS = visual (como aparece)
  • ⚡ JS = comportamento (o que faz)
🎨

CSS controla tudo visual:

Cores, fontes, tamanhos, espaçamentos, bordas, sombras, posições, animações...

📎 3 Formas de Usar CSS

1. Inline (na tag)

<p style="color: red;">Texto</p>

2. Internal (no <head>)

<style>
  p { color: red; }
</style>

3. External (arquivo .css) ✅

<link rel="stylesheet"
      href="estilo.css">

💡 Sempre use External! Mantém HTML e CSS separados, mais organizado e reutilizável.

Parte 1

Seletores CSS

🎯 Seletores — Quem vou estilizar?

SeletorSintaxeSeleciona
Por tagp { }Todos os <p> da página
Por classe.destaque { }Elementos com class="destaque"
Por ID#titulo { }O elemento com id="titulo"
 
/* Por tag: todos os parágrafos */
p { color: blue; }

/* Por classe: elementos com class="alerta" */
.alerta { color: red; }

/* Por ID: o elemento com id="principal" */
#principal { font-size: 24px; }

🆔 Classe vs ID — Qual usar?

✅ Classe (.classe)
<p class="destaque">Texto 1</p>
<p class="destaque">Texto 2</p>

Pode ser usada em vários elementos

⚠️ ID (#id)
<h1 id="titulo">Único!</h1>

Deve ser único na página — só um elemento pode ter aquele ID

💡 Regra de ouro: prefira classes! IDs são úteis para casos especiais (JavaScript, âncoras).

Parte 2

Propriedades CSS Essenciais

🎨 Cores e Texto

h1 {
    color: #00d4ff;              /* cor do texto */
    background-color: #1a1a2e;    /* cor de fundo */
    font-family: Arial, sans-serif; /* fonte */
    font-size: 32px;              /* tamanho da fonte */
    text-align: center;           /* alinhamento */
    font-weight: bold;             /* negrito */
}

Cores podem ser: nomes (red), hexadecimal (#FF0000), ou RGB (rgb(255, 0, 0)).

📦 Box Model — A Base do Layout CSS

Todo elemento HTML é uma caixa retangular com 4 camadas:

MARGIN
BORDER
PADDING
CONTEÚDO 
.card {
    margin: 20px;     /* espaço externo */
    border: 2px solid #ccc; /* borda */
    padding: 15px;    /* espaço interno */
    width: 300px;     /* largura */
}

🔍 DevTools — Inspecionando o Box Model

  1. Abra o Chrome
  2. Clique com botão direito em qualquer elemento
  3. Selecione "Inspecionar" (ou pressione F12)
  4. Na aba Elements, veja o CSS aplicado
  5. No painel Computed, veja o Box Model visual

💡 O DevTools é seu melhor amigo! Use-o sempre para entender por que um elemento está com visual diferente do esperado.

📝 Lista de Exercícios — Aula 04

CSS Layout com Flexbox

📅 04/08/2026 ⏱ 45 minutos 📂 3 exercícios
1
Barra de Navegação Horizontal Básico

Crie uma barra de navegação horizontal usando Flexbox, com 4 links: Home, Projetos, Sobre, Contato.

  • Use uma <nav> com display: flex
  • Os links devem ficar lado a lado, com espaçamento uniforme
  • Estilize com: cor de fundo escura, texto branco, padding, e efeito :hover nos links
💡 Dica: Use justify-content: space-evenly para distribuir os links igualmente. Para remover o sublinhado dos links, use text-decoration: none.
2
3 Colunas de Serviços IoT Intermediário

Crie um layout de 3 colunas usando Flexbox, onde cada coluna representa um "serviço IoT":

  • 🔍 Monitoramento — ícone (emoji), título e descrição
  • ⚙️ Automação — ícone, título e descrição
  • 🔒 Segurança — ícone, título e descrição

As 3 colunas devem ter o mesmo tamanho, com bordas, padding e um espaçamento entre elas usando gap.

💡 Dica: Use flex: 1 nos filhos para que todos ocupem o mesmo espaço.
⭐ Desafio
3
Layout de Página Completo Desafio

Crie um layout de página completo com:

  • Header — com barra de navegação horizontal (Flexbox)
  • Main — com 3 cards lado a lado (Flexbox)
  • Footer — com informações de contato centralizadas

Tudo deve ser estilizado com CSS externo. A página deve usar Flexbox em pelo menos 2 contextos diferentes (navbar + cards).

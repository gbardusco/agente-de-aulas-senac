Parte 2

Flexbox

📐 O Problema: Alinhar Coisas Lado a Lado

Por padrão, <div>s ficam empilhadas verticalmente. Para colocá-las lado a lado, precisamos do Flexbox.

❌ Sem Flexbox
Card 1
Card 2
Card 3
✅ Com Flexbox
Card 1
Card 2
Card 3

🔑 display: flex — O Básico

.container {
    display: flex;  /* Ativa o Flexbox! */
}
<div class="container">
    <div>Card 1</div>
    <div>Card 2</div>
    <div>Card 3</div>
</div>

💡 Regra de ouro: o Flexbox é aplicado no pai (container) e afeta os filhos diretos.

↔️ justify-content — Eixo Horizontal

ValorEfeito
flex-startItens no início (padrão)
flex-endItens no final
centerItens centralizados
space-betweenEspaço igual entre itens
space-aroundEspaço ao redor de cada item
space-evenlyEspaço igual em todos os lados

↕️ align-items — Eixo Vertical

ValorEfeito
stretchEstica para preencher (padrão)
flex-startAlinha no topo
flex-endAlinha na base
centerAlinha no centro vertical

🎯 Centralizar perfeitamente: justify-content: center + align-items: center

🔄 flex-direction e gap

.container {
    display: flex;
    flex-direction: row;      /* horizontal (padrão) */
    flex-direction: column;   /* vertical */
    gap: 20px;               /* espaço entre itens */
}

💡 gap é muito mais prático que usar margin em cada item!

✅ O que aprendemos hoje

  • Revisamos HTML + CSS dos encontros anteriores
  • display: flex transforma um container em Flexbox

  • align-items controla o eixo vertical
  • flex-direction: column empilha itens verticalmente
  • gap define o espaçamento entre itens

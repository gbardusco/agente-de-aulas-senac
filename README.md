# Material Didático - UC14 (IoT)

Este repositório contém o material didático para a Unidade Curricular 14 (IoT) do Senac SP. 

## Estrutura do Projeto

A organização das pastas segue a seguinte estrutura:

- **`.agents/`**: Contém os agentes especializados e as regras globais (`AGENTS.md`) que ditam o funcionamento do workspace.
- **`.docs/`**: Documentos oficiais do curso (ex: Plano de Curso, calendário de aulas).
- **`.memory/`**: Memória persistente do projeto. Aqui estão registrados o status das aulas, decisões pedagógicas/técnicas, feedbacks e o perfil da turma. Consulte sempre a memória antes de fazer alterações.
- **`AULAS/`**: Contém o material didático propriamente dito, organizado por aula, além de assets compartilhados.

## Diretrizes

Este projeto segue diretrizes rigorosas para manter o padrão de qualidade:

1. **Consulte a memória antes de agir:** Sempre verifique a pasta `.memory/` para entender o estado atual do material, da turma e as decisões já tomadas.
2. **Atualize a memória após agir:** Registre em `.memory/` qualquer alteração significativa, decisão ou feedback.
3. **Padrões de Código:** Siga estritamente os padrões técnicos (identação com 4 espaços, adequação do tamanho dos slides, contexto temático da turma, etc). Consulte `.memory/padroes-tecnicos.md`.

## Como Contribuir / Modificar Aulas

- Ao utilizar IA para ajustes, invoque os agentes específicos definidos em `.agents/` conforme a necessidade (ex: planejamento, revisão, criação de exercícios).
- Mantenha a documentação da memória atualizada.

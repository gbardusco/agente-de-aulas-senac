## Observações pedagógicas

### Após Aula 01 (14/07/2026)
- Ritmo de absorção **acima do esperado**.
- Turma produz atividades com velocidade maior do que o planejado inicialmente.
- Recomendação: expandir conteúdo e exercícios por aula.
- **Volume ideal de exercícios por aula:** 5–6 (confirmado após Aulas 01 e 02).

### Pontos fortes da turma
- Já entendem conceitos de entrada/saída (sensores → dados → tela), o que facilita a analogia com HTML (estrutura) → CSS (visual) → JS (comportamento).
- Familiaridade com lógica de programação (C/C++) torna a transição para JavaScript mais suave.
- Motivação alta quando o conteúdo se conecta ao universo IoT que já dominam.

- **Módulo 1 (Aulas 01–06):** HTML + CSS → Projeto: Portfólio Pessoal (1ª avaliação).

## Contexto temático

O conteúdo das aulas, exercícios e exemplos deve estar conectado ao universo profissional da turma. Temas recomendados:

- Cidades Inteligentes
- Sensores de Agricultura
- Domótica (Smart Home)
- Estações Meteorológicas
- Dashboards Industriais
- Fichas Técnicas de Microcontroladores
- Monitoramento de energia, temperatura, umidade (DHT11, LDR, HC-SR04)
- Integração ESP32 → Web (serial, MQTT, HTTP)
